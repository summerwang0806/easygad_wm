3 Experiments and Results
Most main-body tables report all threen-gram windows of the watermark (n=1,2,3) at three operating
points. Unless stated otherwise, the text quotesn-gram=3, the hardest window for both detectors.
3.1 Experimental Setup
Distillation.We evaluate distillation detection across24suspect model architectures,4teacher mod-
els, and4watermarking schemes. In the default setting, the teacher is DeepSeek-R1-Distill-Qwen-
14B (Guo et al., 2025) watermarked with TextSeal (Sander et al., 2026), a dual-key scheme that
samples each token under one of two secret keys, mixed at a fixed rateα=0.1. Following standard
reasoning-distillation protocols, an adversary fine-tunes a Qwen2.5-3B base model (Yang et al., 2024)
for math on1,900quality-filtered OpenR1-Math-220k traces (Hugging Face, 2025) from that teacher.
All traces are generated under one fixed math-teacher system prompt, on which the suspect model is
also conditioned during fine-tuning. We evaluate capability on held-out GSM8K (Cobbe et al., 2021)
and Math-500 (Hendrycks et al., 2021); App. B.2 gives the full distillation setup.
Sampling suspect model outputs.The verifier chooses one domain to audit and draws every prompt
it uses for detection from that domain; it never sees the adversary’s prompts or traces (§2.1). By
default the audited domain is OpenR1-Math-220k (Hugging Face, 2025), held out from the adversary’s
distillation prompts, and every audit stage uses the same system prompt as the distillation traces,
which we call amatched-promptaudit; §3.2 varies both the domain and the system prompt. We read
each suspect on1,900prompts from the test poolX test, disjoint from the distillation promptsXtrain,
and score the first512tokens of every response, around1M tokens per suspect.
