B.4 Detector and Baseline Implementation
This section gives the implementation behind the detector and baseline of §3.1.
Reference key gradient bank and projection.For each candidate key, we generate teacher traces on
the build poolX build (App. B.3), discard responses below the minimum token length in Tab. 8, and
average the surviving reference gradients into∆k. A single fixed random projection, shared by all keys
and applied unchanged to the suspect gradient∆sus so that every cosine the rank test compares is
taken in one coordinate space, approximately preserves their inner products (Johnson et al., 1984; Xia
et al., 2024). We compute this with TRAK (Park et al., 2023). The deployed key and i.i.d. decoys
form the bank used by the rank test in Eq. (4), and its size sets the reportedp-value floor.
